# Sistema de Interlinking — ramperis.com
**Versión:** Septiembre 2026  
**Uso:** Consultar ANTES de redactar o modificar cualquier página. Cada URL tiene su keyword objetivo y un banco de anchors aprobados. Nunca usar el mismo anchor dos veces seguidas en distintos artículos hacia la misma URL. Rotar siempre.

---

## REGLAS DEL SISTEMA

1. **Máximo 1 enlace por URL destino por artículo** — no repetir destino en el mismo post
2. **Rotar anchors** — usar el banco de variaciones, nunca siempre el mismo
3. **Solo si encaja de forma natural** — no forzar un enlace si el contexto no lo permite
4. **Priorizar enlaces desde artículos con más impresiones** hacia las páginas de conversión
5. **Páginas de servicio** (`/breathwork`, `/bano-sonido`, `/sesiones`, `/empresas`) siempre tienen prioridad como destino sobre artículos de blog
6. **Los artículos nuevos** deben tener mínimo 1 enlace interno antes de publicarse
